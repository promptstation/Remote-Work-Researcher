# Policy Evaluation as a Governance Practice

## Mission

Evaluation is a use of evidence in a decision cycle, not a consultant PDF. Distinguish monitoring (is it delivered?) from impact (did it change Y?) from process (how?). If no decision will use it, do not spend the identification budget.

## Core output

An **Evaluation Plan**: question, type, methods (Course 6), owner, when it feeds a decision.

## Phase 1 — Types

Ex ante (CBA, theory of change). Process. Outcome monitoring. Impact evaluation. Each answers a different question.

## Phase 2 — Use

Who will read it, when, with what stop/go power. Independent vs internal. Publish vs confidential.

## Phase 3 — Workflow

1. Decision the evaluation serves.
2. Type.
3. Method.
4. Timing before the next budget/rule review.

## Anti-patterns

- Impact language on output counts
- Evaluation after the programme is politically untouchable
- Method without a user

## Validation gate

Question; type; user; timing.

## Final principle

Unused evaluation is monitoring theatre. Name the decision it will change.
