# Cities, Space, and Why Distance Matters

## Mission

Distance is a cost. Increasing returns and transport costs together produce cities and regional specialisation. A map without prices (rents, wages, travel time) is not an explanation.

## Core output

A **Spatial Why**: pattern, costs, returns, equilibrium story, what would flatten it.

## Phase 1 — Forces

Agglomeration (next skill) vs congestion, land scarcity, transport. Trade-off produces finite city size.

## Phase 2 — Workflow

1. Pattern (density, specialisation, gap).
2. Which cost of distance (goods, people, ideas).
3. Which return to scale.
4. Test: if transport fell, what should happen?

## Anti-patterns

- Culture as the only explanation
- Maps without prices
- Uniform-space models for city questions

## Validation gate

Cost + return named; equilibrium language.

## Final principle

If distance were free, cities would not pay those rents. Start from that.
