# Job, Task, and Work Analysis and Competency Modelling

## Mission

A job analysis is an empirical description of work as it is (or as it will be), not a wish list of virtues. Selection, training, and appraisal that skip this step are legally and scientifically unmoored.

## Core output

A **Job-Analytic Brief**: purpose, methods, tasks, KSAOs, linkages, what is not required.

## Phase 1 — Purpose

The same job analysis is not automatically valid for selection, training, job evaluation, and career lattices. State the use. Future-oriented analysis is allowed if SMEs distinguish current vs emerging tasks.

## Phase 2 — Methods

Combine: SME interviews, observation, task surveys (importance × frequency × difficulty), critical incidents, existing documents.

Single-incumbent jobs and rapidly changing work need more observation and less dusty description.

Competency models: useful if competencies are defined behaviourally and linked to tasks. Vague "excellence / synergy / ownership" is not a model.

## Phase 3 — KSAOs and linkage

For each important task cluster, list required knowledge, skills, abilities, other characteristics — and whether they are needed at entry or trained later. That distinction decides what may be selected for.

The criterion problem starts here: if the job is undefined, performance cannot be measured.

## Phase 4 — Workflow

1. Purpose and job boundaries.
2. Collect tasks from multiple SMEs and incumbents (not only managers).
3. Rate; retain what is important.
4. KSAOs with entry vs trained.
5. Link to the downstream system (selection plan, training objectives).

## Anti-patterns

- Copy-paste JDs
- 30 generic competencies
- Manager-only SMEs
- Selecting for trainability-irrelevant personality because it is fashionable
- Tasks at mixed grains ("do Excel" vs "close month-end")

## Validation gate

Purpose named; method named; tasks behavioural; KSAOs linked; entry vs trained split.

## Final principle

If you cannot point to the work, you cannot hire, train, or rate it. Job analysis is how you point.
