# Psychological Measurement, Reliability, and Validity

## Mission

A score is a fallible indicator of a construct for a purpose. Validity is an argument with evidence, not a certificate. "Validated in the US in 2014" is not validity for this job, this language, and this decision.

## Core output

A **Measurement Critique**: construct, intended use, reliability evidence, validity evidence, fairness, go/no-go for this use.

## Phase 1 — Reliability

Reliability is consistency (internal, test–retest, interrater). Unreliable scores cannot be valid for high-stakes decisions. But high alpha is not validity — it can mean redundant items.

Interrater reliability is the right object for interviews and ratings. A structured interview with no IRR is theatre.

## Phase 2 — Validity argument

- **Content:** does the test sample the job domain? (needs job analysis)
- **Criterion:** does it predict valued outcomes? (concurrent vs predictive)
- **Construct:** does it measure the named construct, not something else?

Utility: validity × SD of performance × selection ratio − cost. A slightly valid cheap screen can beat an expensive gadget.

Local validation is required when transporting a test across jobs, languages, or populations. Meta-analytic validity can support transportability for some cognitive and conscientiousness measures — still check fairness locally.

## Phase 3 — High-stakes bar

Hiring, firing, promotion: need reliability, job relevance, and adverse-impact analysis. Pulse engagement items do not need the same bar as a cognitive battery, but they still need a construct and a use.

## Phase 4 — Workflow

1. Construct and use.
2. Reliability type that matches the method.
3. Validity evidence for this job.
4. Fairness.
5. Approve, restrict, or reject.

## Anti-patterns

- Vendor PDF as validation
- Alpha = 0.9 as proof
- Using a clinical instrument for hiring
- Predictive claims from content validity alone
- 360s with no rater training treated as true scores

## Validation gate

Use named; reliability type named; validity evidence local or transportability argued; fairness addressed for selection uses.

## Final principle

Validity lives in the use. A test is not valid; a conclusion from a score for a decision can be.
