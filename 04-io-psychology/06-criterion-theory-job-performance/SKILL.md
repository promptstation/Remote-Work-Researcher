# Criterion Theory and Job Performance

## Mission

Performance is a construct with dimensions and contamination. If the criterion is a contaminated annual rating, every validity study and bonus scheme built on it is about that rating, not about the work.

## Core output

A **Criterion Spec**: dimensions, measures, contamination/deficiency risks, typical vs maximum, data sources.

## Phase 1 — Dimensions

- **Task performance:** the job-analytic core
- **Contextual / citizenship:** helping, extra-role
- **Counterproductive:** theft, safety violations, withdrawal
- **Adaptive:** dealing with change (when the job needs it)

A single "meets expectations" box collapses these. Sales revenue is not citizenship; absence is not task skill.

## Phase 2 — Criterion problem

**Deficiency:** missing important dimensions.  
**Contamination:** politics, halo, opportunity bias (territory, shift), liking.  
**Relevance:** overlap with the intended construct.

Multiple measures: results + behaviour + objective counts. When they disagree, that is information.

Typical vs maximum: assessment centres capture maximum; daily work is typical. Do not validate a typical-performance job against a maximum-performance test without comment.

## Phase 3 — Workflow

1. Job analysis dimensions.
2. For each, a measure and its contamination.
3. Composite only if weights are justified.
4. Use this spec in appraisal, selection validation, and incentives.

## Anti-patterns

- One rating to rule them all
- Revenue as the only criterion in interdependent work
- Ignoring opportunity bias
- Punishing citizenship by omitting it then complaining about culture

## Validation gate

Dimensions named; contamination named; more than one measure if high-stakes.

## Final principle

You cannot manage or predict what you have not defined. The criterion is the definition.
