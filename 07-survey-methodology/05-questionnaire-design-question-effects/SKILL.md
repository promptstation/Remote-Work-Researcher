# Questionnaire Design and Question Effects

## Mission

An item is a measurement protocol: comprehension, retrieval, judgment, reporting. Wording and order are treatments. Percentages from bad items are precise measures of something else.

## Core output

An **Instrument Critique or Draft**: constructs, items, order, scales, sensitive-topic method, cognitive-test plan.

## Phase 1 — Cognitive process

Misread words, cannot retrieve, satisfy (satisficing), socially desirable. Double-barrelled, double negatives, leading, undefined time windows — rewrite.

## Phase 2 — Design rules

One construct per item. Specify period. Balanced scales. Don't know distinct from neutral when it matters. Sensitive: self-admin, forgiving wording, randomised response only if you can analyse it.

Order: context effects; randomise where order is arbitrary; do not put the outcome after a long treatment-priming block without comment.

## Phase 3 — Translation

Translate and adapt; back-translate is not enough. Pretest in each language.

## Phase 4 — Workflow

1. Constructs.
2. Draft.
3. Cognitive interviews / pretest.
4. Freeze; version control.

## Anti-patterns

- Agreement with a long agree-sounding statement
- "And" items
- Changing wording mid-panel and calling it a trend
- No pretest

## Validation gate

Construct=item; period specified; pretest; order considered.

## Final principle

The questionnaire is the instrument. If you did not design it, you do not know what the percentage means.
