# Modes of Administration

## Mission

Mode changes who answers and how they answer. Web is cheap and coverage-poor in some populations. F2F is expensive and better for complex/sensitive with good interviewers. Mixing modes without a mode-effect plan breaks trends.

## Core output

A **Mode Plan**: primary mode, coverage implication, measurement implication, mixed-mode rule if any.

## Phase 1 — Trade

| Mode | Coverage | Measurement |
| --- | --- | --- |
| F2F | can be high | interviewer effects; good for complex |
| Phone | declining in some places | shorter items; no visuals |
| Web | internet users | visual; low social desirability on some topics; bots |
| Paper | literacy | slow |

## Phase 2 — Mixed mode

Same questions can yield different answers by mode. Sequential mixed mode to raise response is common; analyse with mode as a feature or design to minimise difference. Do not splice a web year onto an F2F trend silently.

## Phase 3 — Workflow

1. Who must be covered?
2. Question complexity/sensitivity.
3. Budget.
4. Mode; if mix, a comparability plan.

## Anti-patterns

- Web form as national
- Mode change called trend
- Long grids on phones

## Validation gate

Mode named; coverage; trend comparability if relevant.

## Final principle

Mode is part of the measurement. Change it and you may have changed the estimand.
