# Payroll Operations and the Payroll–HRIS Interface

## Mission

Payroll is a control environment: cutoff, inputs, calculate, exception, pay, recon, statutory filings. Outsourcing does not outsource accountability for inputs. HRIS events (hire, salary, leave, terminate) must arrive before cutoff.

## Core output

A **Payroll Control Spec**: calendar, input list, SoR per input, recon points, exception SLA, retro policy.

## Phase 1 — Inputs

New hires, terms, salary changes, time, bonuses, deductions, tax codes. Each has an owner and a cutoff. Late inputs are retros, not miracles.

## Phase 2 — Controls

Segregation: who can change a bank account vs who approves. Bank-file dual control. Ghost-employee recon (HRIS vs pay vs access). Variance vs last cycle.

## Phase 3 — Workflow

1. Calendar.
2. Input-owner table.
3. Pre-pay exception report.
4. Post-pay recon.
5. Retro log.

## Anti-patterns

- "Payroll will fix it"
- No cutoff
- Unreconciled HRIS vs payroll headcount
- One person with god rights

## Validation gate

Cutoff; recon; SoD; input owners.

## Final principle

Pay is a controlled calculation. If you cannot recon it, you cannot defend it.
